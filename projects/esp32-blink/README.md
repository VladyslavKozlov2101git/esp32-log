# ESP32: перші кроки

Навчальний проєкт: блимання вбудованим LED + вивід у Serial.

> **Важливо:** проєкт лежить у `C:\esp32\esp32-blink`, а не в папці з кирилицею.
> Ланцюжок Xtensa/ESP-IDF на Windows не вміє працювати з не-ASCII символами
> в шляху — лінкування падає з помилкою `cannot open map file`.
> Тримайте всі ESP32-проєкти на шляху без кирилиці, пробілів і OneDrive.

## Апаратне забезпечення

- ESP32 DevKit (ESP32-WROOM-32), micro-USB
- USB-кабель **з підтримкою передачі даних** (не «тільки зарядка»)
- Драйвер USB-моста: **CP2102** (Silicon Labs) або **CH340** (WCH) — залежить від плати

## Швидкий старт

1. Підключіть плату кабелем даних.
2. Перевірте, що в Диспетчері пристроїв з'явився порт `COMx`
   (розділ «Порти (COM і LPT)»).
3. Відкрийте цю папку у VS Code (`code .`).
4. PlatformIO автоматично підтягне залежності при першому білді.
5. Зберіть: кнопка **Build** (✓) або `pio run`.
6. Завантажте: кнопка **Upload** (→) або `pio run -t upload`.
7. Монітор: `pio device monitor` (або іконка монітора в статус-барі).

## Якщо плата не визначається

- Інший кабель (найчастіша причина) та інший USB-порт.
- Драйвер:
  - CP210x: https://www.silabs.com/developer-tools/usb-to-uart-bridge-vcp-drivers
  - CH340/CH343: https://www.wch-ic.com/downloads/CH341SER_EXE.html
- Після встановлення драйвера перепідключіть плату.
- Якщо завантаження «зависає» на `Connecting...`: затисніть кнопку **BOOT**,
  натисніть **EN/RST**, відпустіть **RST**, потім відпустіть **BOOT**.

## Куди рухатись далі

| Крок | Що зробити | Що вивчите |
| --- | --- | --- |
| 1 | Blink (цей проєкт) | структура скетчу, GPIO, Serial |
| 2 | Кнопка + LED | `digitalRead`, внутрішній pull-up, антидребезг |
| 3 | PWM (LEDC) | плавне регулювання яскравості |
| 4 | АЦП + потенціометр | `analogRead`, шум АЦП |
| 5 | DHT22 / BME280 | I2C/OneWire, сторонні бібліотеки |
| 6 | Wi-Fi: точка доступу | `WiFi.h`, HTTP-сервер на платі |
| 7 | Wi-Fi: MQTT/Telegram | клієнт-сервер, JSON |
| 8 | FreeRTOS задачі | `xTaskCreate`, черги, семафори |
| 9 | Deep sleep | живлення від батареї |

## Корисні команди PlatformIO

```bash
pio run                 # зібрати
pio run -t upload       # прошити
pio device list         # які COM-порти є
pio device monitor      # Serial-монітор (Ctrl+C для виходу)
pio run -t clean        # очистити build
pio system info         # інформація про середовище
```
